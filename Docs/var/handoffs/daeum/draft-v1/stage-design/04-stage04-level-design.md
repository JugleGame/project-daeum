# Stage 4 — Dormitory 레벨디자인

근거 카드: ELEM-048(일상 유대·공포 대비), ELEM-061, ELEM-060, ELEM-058.
근거 spec: `daeume__spec-004-remnant-enemies`, `daeume__spec-012-combat-encounters`.

## 스테이지 개요

조금 더 밝고 유쾌한 기억. 방·복도·계단을 지나며 전투. 신규 적 유형 없음 — 근접형+돌진형
유지, 수는 Stage3과 동급(수 증가는 Stage5부터). 이 스테이지의 핵심은 난이도가 아니라
**톤 대비**: 기억 자체는 행복하지만 기억이 끝나면 몬스터가 다시 나온다는 것 자체가 섬뜩함.

## 톤 원칙 (ELEM-048)

- 조명·색 팔레트는 전투·추격 중에도 어둡게 꺾지 않는다 — 대비는 어둠이 아니라 "밝은 공간에
  괴물이 있다"는 병치에서 나온다. 어두워지는 톤 전환은 Stage7부터 시작(계획서 원칙).
- 배경 소품(간식 봉지, 보드게임, 이불 요새)은 전투 지형과 겹치되 파괴 연출 없이 그대로 둔다.

## Zone A — 공용 라운지

- `stage04.encounter.01`: `EnemyType=Melee 1 + Dash 1`, `WaveCount=1`
- 이불 요새·소파로 은폐 라인 형성, 밝은 조명 유지

## Zone B — 복도

- `stage04.encounter.02`: `Melee 2`, `WaveCount=1` — Stage2 복도 재탕이 아니라 소품(빨래 바구니,
  방문 앞 신발)으로 동일 구조를 다르게 읽히게(ELEM-061: 반복 구조라도 표면 디테일로 신선도 유지)

## Zone C — 계단

- `stage04.encounter.03`: `Dash 2`, `WaveCount=1` — 계단참 좁은 폭에서 돌진 예고 회피 난이도 상승
- 붙잡기 벽 재확인(난간 매달리기)

## Zone D — 개인 방 / 박스

- `stage04.memory.anchor.01`: 전투 없음. 기억은 "함께 놀거나 장난친 일상"
- 방 안 소품(포스터, 낙서)에 두 사람 흔적을 시각적으로 배치 — 대사 없이 관계 밀도 전달

## Zone E — 추격 구간

- `stage04.chase.start` → `stage04.escape`: Zone A~C 공간을 밝은 조명 그대로 역주행
- 장애물은 기존 소품(빨래 바구니, 이불 요새) 넘어뜨리며 통과 — 신규 장애물 추가 없음(ELEM-051)
- 연출 지침: 몬스터 등장 시에도 BGM·조명 급변 없음. "행복한 기억이 끝났다"는 정적 자체가 신호

## Role B 앞 확인 요청

- 제안 결정: Stage4~6은 Overlay 강도 상한을 기본값(전 스테이지 균일 적용 시)의 약 30%로
  캡하는 스테이지별 예외값을 둔다(Stage7부터 캡 해제, 기본값 그대로). 정확한 캡 수치는
  Contamination Overlay 구현 담당이 톤 원칙(§ 톤 원칙)만 보고 확정.
