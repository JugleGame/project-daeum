# Stage 1~13 레벨디자인 개요 (일관성 체크용 요약)

개별 문서(01~13)를 읽기 전 전체 커브를 먼저 확인하는 용도. 개별 문서와 이 표가 어긋나면
개별 문서가 우선한다(이 표는 파생 요약).

## 적 유형 도입 순서

| Stage | 신규 유형 | 비고 |
|---|---|---|
| 1 | 없음 | remnant marker 비활성(장식만) |
| 2 | 근접형(Melee) | 최초 실전 전투 |
| 3 | 돌진형(Dash) | 원거리형은 보류 |
| 6 | 원거리형(Ranged) | 트인 공간 확보 후 도입 |
| 11 | (신규 유형 없음) | 전 유형에 `protagonist_*` 태그 부착 시작 |
| 13 | Reactive(비선공) | 후반 밀도 감소용, 신규 아키타입 아님 |

## 지형 위험요소(TerrainHazardIds) 도입 순서

| Stage | Hazard | spec-012 선언 3종 매핑 |
|---|---|---|
| 3 | 흔들리는 선반 | 3종 외 커스텀 추가 |
| 7 | 얼음 균열 발판 | 무너지는 발판 |
| 7 | 눈길 이동 발판 | 이동 플랫폼 |
| 8 | 셔터 문(칸막이) | 순차 폐쇄 셔터 문 |
| 10 | 위 3종 연속 배치(신규 없음) | 총동원 |
| 12 | 셔터+이동 발판 재스킨(신규 없음) | 병상 칸막이·커튼 레일 |

## 전투 밀도 커브 (Zone C 기준 동시 스폰 수 대략치)

1(0) → 2(1) → 3(2) → 4(2) → 5(5, 웨이브2) → 6(4) → 7(3) → 8(5, 웨이브2) → 9(5) →
10(7, 웨이브2, 정점 근접) → 11(4, 인간형 전환 우선) → **12(8, 웨이브3, 캠페인 전체 최댓값)** →
13(감소, 3→2→1→0)

## 톤 커브

- Stage1~3: 중립
- Stage4~6: 밝음 유지(ELEM-048 대비 원칙), Stage6이 대비 최고조
- Stage7: 어두워지기 시작(첫 전환점)
- Stage8~12: 점진적으로 무거워짐, Stage10부터 병원 이미지 직접성(`HospitalImageryDirectness`)
  0→1(10)→2(11)→4(12, 최댓값)
- Stage13: 규칙 자체가 깨짐(전투가 아니라 수용)

## 추격(Chase) 길이 커브

- Stage1: 최단(첫 학습, 판정 자체를 가르침)
- Stage2~9: 완만히 증가, 매 스테이지 기존 장애물만 재활용(ELEM-051 원칙)
- Stage10: 캠페인 중 두 번째로 긴 구간(지형 3종 총동원)
- Stage12: **전체 최장**(director `TargetChaseSeconds` 최댓값)
- Stage13: 전통적 추격 아님 — 20~30초 왕복 루프 + 무기 내려놓기로 대체(spec-009)

## 문서별 상태

각 `0N-stageNN-level-design.md`의 "Role B 앞 확인 요청" 항목은 가능한 한 제안값/결정으로
채워뒀다. "(미해결, 비차단)"로 표기된 항목만 실제 추가 조율이 필요하고, 나머지는 실측 후
숫자만 조정하면 되는 수준이다.
